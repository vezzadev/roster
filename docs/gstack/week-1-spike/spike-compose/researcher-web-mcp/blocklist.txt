# Researcher web-fetch contamination blocklist.
#
# Source of truth: ../../t4-mcp-investigation.md "Researcher domain blocklist".
# Keep these in sync if either side changes.
#
# Syntax:
#   - Lines starting with # are comments.
#   - Plain hostname (no slash, no asterisk) blocks that host + any subdomain.
#     Example: bcg.com blocks bcg.com AND www.bcg.com AND web-assets.bcg.com.
#   - Lines containing '/' or '*' are treated as patterns matched (case-insensitive
#     substring with * → .*) against the full lowercased URL AND against host+path.
#     Use this form for path-specific blocks (pwc.com/consulting) and archive
#     mirrors (web.archive.org/web/*/bcg.com/*).
#
# Hostname blocks also become the excludeDomains array on every Firecrawl
# /v2/search call — server.py reads BLOCK_HOSTS for that. Pattern entries are
# enforced only on scrape (Firecrawl /search doesn't expose path patterns).
