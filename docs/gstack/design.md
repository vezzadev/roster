## Executive Summary

Docker-compose for human+AI teams. One YAML file defines roles, skills, tools.
`roster up` provisions chat, email, files, memory. Take over any role via GUI.
`roster down` tears it all down. Open protocol, open source.

**v1 product:** one canned `research-desk` template (Engagement Manager + 2 Senior
Analysts + Researcher) producing the kind of market-entry brief a boutique consultancy
charges five figures for. Almost every multi-agent product today is a coding tool;
Roster is not.

**Stack:** Nextcloud + Migadu + Letta on Docker Compose, localhost-only in v1.

**Key bets:**
1. **Templates first, YAML composition later.** Canned `research-desk` only in v1;
   measure demand for custom composition via issue requests.
2. **Real infrastructure as shared workspace.** Nextcloud + Migadu give agents
   real identities, mailboxes, files. Two requirements: MCP servers for AI roles
   + credential rotation for human takeover. Backend is swappable.
3. **Letta as agent runtime.** Memory persistence + multi-channel messaging +
   agent lifecycle out of the box. Lower integration surface than raw Claude
   Agent SDK with more capabilities.
4. **Takeover via credential rotation = best-effort containment, not hard kill.**
   Stops a confused/looping agent from new actions; does not undo prior
   exfiltration. Adversarial-agent hardening is v1.x research.
5. **Validation gates ship.** Week 1 = manual-config spike that has to produce
   an analyst-grade brief before any provisioner code lands.

**Effort:** Solo founder, sabbatical. **10-12 weeks aspirational / 16-20 weeks
realistic** under the chosen Development Standards (TDD + 4 test layers +
subagent-driven dev + human PR review). Week 6 is the explicit re-baseline
checkpoint.

**Cost target:** $119-239/mo for a 4-agent team (Migadu $19 + Claude API
$100-200 + ~$0-20 compute).
